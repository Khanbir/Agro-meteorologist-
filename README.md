Даний проєкт спрямований на прогноз та аналізу погодних умов для планування подальшиш сівозмін. Для цього за допомогою Python коду проводиться викачка архіва погоди за замовчуванням - за координатами -  м.Кривий Ріг, за 10 років. Потім згідно викачаному архіву погоди проводиться аналіз архіву погоди (середня максимальна, середня мінімальна погода і тд.. з віазуалізацією цих даних та збереження звіту в пдф файлі.
